# relay

A feature-complete Model Context Protocol (MCP) implementation for Gleam: server and client, stdio and Streamable HTTP.

Status: design-stage; see [relay-design.md](https://github.com/gleam-dream/oversight/blob/master/relay-design.md) in [gleam-dream/oversight](https://github.com/gleam-dream/oversight). Not yet published to Hex.

Ports/wraps: Model Context Protocol.

## Development

```sh
nix develop
gleam test
```
